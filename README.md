# DataAnalytics

Experiência web para uma aula inaugural de pós-graduação em Data Science & Analytics.

## Conceito

**Problema → Dados → Inteligência → Ação → Impacto**

O site foi desenhado como uma narrativa navegável, não como um conjunto tradicional de slides.

## Stack

- Next.js
- React
- TypeScript
- Framer Motion
- Lucide Icons

## Executar localmente

```bash
npm install
npm run dev
```

Depois acesse `http://localhost:3000`.

## Qualidade

```bash
npm run typecheck
npm run lint
npm run build
```

## Modo apresentação

Use o botão **Apresentar** no topo. Durante a apresentação:

- `→` ou `↓`: próxima seção
- `←` ou `↑`: seção anterior
- `Esc`: sair do modo apresentação

## Estrutura narrativa

1. Problema
2. Pipeline de dados
3. Maturidade analítica
4. Ecossistema técnico
5. Aplicações
6. Carreiras
7. Provocação final


## Publicação

O projeto está configurado para publicação automática no GitHub Pages por GitHub Actions.
